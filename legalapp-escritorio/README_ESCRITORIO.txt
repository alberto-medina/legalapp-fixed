BASE DE TRABAJO: LEGAL APP ESCRITORIO

Esta carpeta es una copia separada para adaptar Legal App a desktop sin tocar la base estable movil.

Objetivo inicial:
- Windows desktop
- Mantener login, perfiles, paneles, chat, historial y pagos web
- Adaptar solo lo que hoy depende de Android

Estado actual:
- Perfil de foto ya tiene fallback para escritorio con selector de archivos.
- Chat ya tiene base para adjuntar archivos y abrirlos en escritorio.
- Pagos y videollamadas ya usan navegador fuera de Android.
- Grabacion de audio sigue pensada para Android y queda pendiente una version desktop.
- Camara de escritorio ahora puede degradar a seleccionar una imagen si no hay provider de camara.

No usar esta carpeta para compilar Android estable.
