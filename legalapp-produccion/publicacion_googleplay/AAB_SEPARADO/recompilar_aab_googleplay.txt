===========================================
PASO 3 - UBUNTU - ajustar buildozer.spec SOLO en esta copia (AAB, no APK)
===========================================

OJO - CLAVE CORREGIDA 2026-07-25: la clave real que usa Buildozer para el
target SDK es "android.api", NO "android.targetapi". Esa clave "android.targetapi"
no existe en Buildozer, se ignora en silencio y Buildozer usa su default interno
(33) sin importar lo que diga el .spec. Confirmado leyendo buildozer/targets/android.py
(la property android_api lee 'android.api', no 'android.targetapi').
Esto costo dos recompilaciones fallidas antes de detectarlo - no repetir el error.

sed -i 's/android.targetapi = 33/android.api = 35/' buildozer.spec
sed -i 's/android.release_artifact = apk/android.release_artifact = aab/' buildozer.spec

# Verificar que quedo bien antes de compilar (NO debe aparecer "android.targetapi"):
grep -E "android.api|android.targetapi|android.release_artifact|android.permissions|gradle_dependencies" buildozer.spec

===========================================
PASO 4 - UBUNTU - borrar cache de dist si ya habia una build previa
===========================================

Si esta carpeta ya compilo antes con otro target API, Buildozer reutiliza el
"dist" cacheado en .buildozer y puede no regenerar el manifest correctamente.
Borrar antes de compilar cada vez que se cambia android.api:

rm -rf .buildozer/android/platform/build-arm64-v8a_armeabi-v7a/dists

===========================================
PASO 5 - UBUNTU - compilar
===========================================

buildozer android release

(la primera vez puede tardar bastante -- descarga NDK/SDK. Si ya compilaron
ahi antes, deberia ser bastante mas rapido por el cache de .buildozer, salvo
que se haya borrado el dist en el paso anterior)

===========================================
PASO 6 - UBUNTU - verificar el target SDK real (no confiar solo en el .spec)
===========================================

grep -o 'targetSdkVersion="[0-9]*"' .buildozer/android/platform/build-arm64-v8a_armeabi-v7a/dists/legalapp/build/intermediates/merged_manifests/release/processReleaseManifest/AndroidManifest.xml

Debe decir targetSdkVersion="35". Si dice otra cosa, no seguir - repetir desde el paso 4.

===========================================
PASO 7 - UBUNTU - verificar salida y firma
===========================================

ls -lh bin/

# Verificar si el .aab ya quedo firmado:
jarsigner -verify -verbose -certs bin/*.aab

# Si NO esta firmado (el comando anterior dice "jar is unsigned"), firmarlo:
jarsigner -verbose -sigalg SHA256withRSA -digestalg SHA-256 \
    -keystore legalapp-release.keystore bin/legalapp-*-release.aab legalapp
# (va a pedir la contrasena del keystore)
