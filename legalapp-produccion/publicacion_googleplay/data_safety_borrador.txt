DATA SAFETY - LEGAL APP - RESPUESTAS LISTAS PARA CARGAR EN PLAY CONSOLE
Verificado directo contra el codigo (supabase_config.py, fcm_service.py,
videollamada.py, network_security_config.xml) el 2026-07-25. No son supuestos.

===========================================
PREGUNTA 1: Seguridad de los datos - cifrado en transito
===========================================
Respuesta: SI, todos los datos se envian cifrados en transito.

Evidencia:
- network_security_config.xml tiene cleartextTrafficPermitted="false" como base
  (bloquea HTTP sin cifrar). Las unicas excepciones son localhost/IPs de red local
  (10.0.0.0, 192.168.0.0, 127.0.0.1), usadas solo en desarrollo, nunca en produccion.
- Supabase: todas las llamadas van a https://xzkojjgymuvhscphvsdw.supabase.co (HTTPS)
- Firebase: SDK oficial, HTTPS por defecto
- MercadoPago: se accede via Edge Function de Supabase (HTTPS) que devuelve un
  link de checkout hosteado por MercadoPago (tambien HTTPS)

===========================================
PREGUNTA 2: Eliminacion de datos
===========================================
Respuesta: SI, se puede solicitar la eliminacion de los datos.

Evidencia:
- Mecanismo en la app: boton "BORRAR CUENTA" en Mi Perfil (views/perfil.py,
  funcion _eliminar_cuenta -> supabase_config.eliminar_cuenta_completa).
  Borra en cascada: mensajes de chat, resenas, codigos de verificacion,
  solicitudes de retiro, consultas (como cliente y como abogado), foto de
  perfil del storage, y el registro de usuario. Tambien revoca el token de
  sesion de Firebase.
- Mecanismo web (sin necesidad de instalar la app):
  https://cumbrelabs.com.ar/legalapp/eliminacion-de-cuenta.html

PREGUNTA 3: Tipos de datos recolectados
===========================================

-- INFORMACION PERSONAL --
[x] Nombre                  - Recolectado y compartido: NO compartido. Uso: funcionalidad de la app (identificar al usuario en consultas/chat)
[x] Direccion de email      - Recolectado, no compartido. Uso: cuenta, autenticacion, comunicaciones
[x] Numero de telefono      - Recolectado, no compartido. Uso: funcionalidad de la app (contacto)
[x] ID de usuario           - Recolectado, no compartido. Uso: cuenta (uid interno)
[x] Direccion fisica        - CORREGIDO 2026-07-25: SI se recolecta. views/register.py
    pide "dni" y "direccion" al registrar un cliente (no solo provincia/ciudad).
    Recolectado, no compartido. Uso: funcionalidad de la app (identificacion para
    la consulta legal)
[x] Otra info personal      - Recomendado declarar aca la info profesional del
    abogado (matricula, experiencia, bio, especialidades). Recolectado, no
    compartido. Uso: funcionalidad de la app

-- INFORMACION FINANCIERA --
[x] Info de cuenta bancaria - Recolectado (CBU/alias de retiro del abogado, campo
    cuenta_bancaria), no compartido con terceros salvo el propio abogado. Uso:
    funcionalidad de la app (pagar honorarios)
[x] Historial de compras    - Recolectado (registro de consultas pagadas, montos,
    suscripciones). Uso: funcionalidad de la app
[ ] Numero de tarjeta/datos de pago - NO se recolecta directamente: el pago se
    hace en el checkout hosteado de MercadoPago (init_point), la app nunca ve
    ni almacena numero de tarjeta. IMPORTANTE marcar que se COMPARTE con
    MercadoPago como procesador de pagos para completar la transaccion.

-- MENSAJES --
[x] Otros mensajes in-app   - Recolectado (mensajes de chat entre cliente y

===========================================
CON QUIEN SE COMPARTEN DATOS (terceros)
===========================================
- Supabase (base de datos, autenticacion, storage de archivos) - infraestructura
- Firebase (autenticacion + notificaciones push FCM) - infraestructura
- MercadoPago (procesamiento de pagos) - recibe email y monto para generar el
  checkout; los datos de tarjeta los procesa MercadoPago directamente, nunca
  pasan por los servidores de Legal App
- Jitsi Meet (videollamadas) - solo recibe el nombre de sala generado, no datos
  personales del usuario mas alla de lo que el propio Jitsi pida al conectarse

No se vende informacion a terceros con fines publicitarios. No hay SDK de
publicidad ni de analytics de terceros en la app.
